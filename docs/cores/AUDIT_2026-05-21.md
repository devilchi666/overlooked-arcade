# Per-core ROADMAP staleness audit — 2026-05-21

The per-core `ROADMAP.md` files were written when each system onboarded but
haven't been updated as the project-wide cross-system infrastructure has
landed. Many items still marked `⬜` are actually shipped — closed
incidentally by Phase 1.5, Phase 2.5–2.8, Phase 3, Phase 4, the direct-launch
CLI (2026-05-20→21), or various cross-system input infra (analog axes
2026-05-20 morning, POINTER device 2026-05-20 afternoon, keyboard
passthrough 2026-05-19→20).

This document is the authoritative reference for what's actually open per
system. The per-core ROADMAPs each carry a 2026-05-21 footer pointing here;
their original `⬜` bullets are retained for history.

## How to read each entry

- **Stale (cross-system):** item is actually shipped — close on sight.
- **CODE (open):** real coding work nobody else is doing; I/we could ship.
- **OPERATOR (open):** human-at-controller work — playtests, validation,
  preference decisions.
- **DATA (open):** curation / asset / playtime work that doesn't fit either
  bucket.

Items I skip:
- Anything truly already `✅` in the ROADMAP.
- Anything tagged as deferred-until-forced (shared analog infra, etc.) that
  hasn't been triggered by a real demand.
